## 6. HOW TO REPORT ISSUES

### Step-by-Step Issue Reporting Process

#### Step 1: Document the Issue

**Gather Information:**
- What were you doing when the issue occurred?
- What did you expect to happen?
- What actually happened?
- When did it first happen?
- How often does it happen? (Always, sometimes, once?)
- What browser/device were you using?

**Take Screenshots:**
- Screenshot of the error message (if any)
- Screenshot of the unexpected behavior
- Include URL or page name

#### Step 2: Reproduce the Issue

**Try to reproduce:**
1. Clear your browser cache (Ctrl+Shift+Delete)
2. Try again in a different browser (Chrome, Firefox, Safari)
3. Try on a different device if possible
4. Note if it's reproducible or intermittent

#### Step 3: Prepare Bug Report

**Email Template:**

```
Subject: [URGENT/HIGH/MEDIUM/LOW] Issue Report — [Feature Name]

To: [Developer Email]

Issue Description:
What is the problem?

Steps to Reproduce:
1. [Step 1]
2. [Step 2]
3. [Step 3]

Expected Result:
What should happen?

Actual Result:
What actually happened?

Environment:
- Browser: Chrome 95 / Safari / Firefox
- Device: iPhone 12 / Windows PC / iPad
- URL: [FILL IN]/admin/dashboard.php
- Time: April 22, 2026 at 3:45 PM

Attachments:
- Screenshot 1: [error.png]
- Screenshot 2: [screen.png]

Priority: [CRITICAL/HIGH/MEDIUM/LOW]
Impact: How is this affecting your business?
```

#### Step 4: Submit Bug Report
